# Rise and Sine

A single-page app for exploring sun angles throughout the year. It will show a sinusoidal curve with adjustable parameters such as latitude and time.

## Local setup

Install [Vite+](https://viteplus.dev/guide/), then run:

```sh
vp install
vp run dev
```

To build and preview the app:

```sh
vp run build
vp run preview
```
